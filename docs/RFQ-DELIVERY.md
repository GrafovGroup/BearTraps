# Retired RFQ integration

The latest Phase 1C owner decision supersedes the former RFQ/basket/tender delivery model. These features are no longer public. `/request-quote/` and `/equipment-package/` redirect to `/contact/`; old server/basket modules remain internal historical code and are not deployed or imported by public pages.

See [contact delivery](CONTACT-DELIVERY.md) for the active simple enquiry adapter and activation requirements. The Phase 1B report records historical RFQ behavior; it does not describe the Phase 1C public interface.
